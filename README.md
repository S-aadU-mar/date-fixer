Start by setting up a python virtual environment within the project folder (ONLY ONCE):
```console
python -m venv .venv
```
Activate the environment (EACH TIME):
```console
.venv\Scripts\Activate.ps1
```
Install dependencies (ONLY ONCE):
```console
pip install -r requirements.txt
```
Run the app (EACH TIME):
```console
streamlit run app/date_cleaner.py
```
